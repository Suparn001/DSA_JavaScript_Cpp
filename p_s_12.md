
# Maximum Points You Can Obtain from Cards

## Problem Description

You are given an integer array `cardPoints` and an integer `k`.

There are several cards arranged in a row, and each card has an associated number of points. You can take exactly `k` cards from the beginning or the end of the row. Your score is the sum of the points of the cards you have taken.

Return the maximum score you can obtain.

---

## Approach

- Start by summing the first `k` cards from the left.
- Then, gradually replace cards from the left with cards from the right, one by one.
- Track the maximum sum obtained during this process.

This sliding window approach has a time complexity of **O(k)** and space complexity of **O(1)**.

---

## Java Implementation

```java
class Solution {
    public int maxScore(int[] cardPoints, int k) {
        int leftSum = 0;
        int rightSum = 0;
        int maxSum = 0;
        int n = cardPoints.length;

        // Sum first k elements from the left
        for (int i = 0; i < k; i++) {
            leftSum += cardPoints[i];
        }
        maxSum = leftSum;

        // Slide window: remove one from left, add one from right each iteration
        for (int i = 1; i <= k; i++) {
            leftSum -= cardPoints[k - i];
            rightSum += cardPoints[n - i];
            maxSum = Math.max(maxSum, leftSum + rightSum);
        }
        return maxSum;
    }
}
```

## C++ Implementation

```cpp
class Solution {
public:
    int maxScore(vector<int>& cardPoints, int k) {
        int leftSum = 0;
        int rightSum = 0;
        int maxSum = 0;
        int n = cardPoints.size();

        // Sum first k elements from the left
        for (int i = 0; i < k; i++) {
            leftSum += cardPoints[i];
        }
        maxSum = leftSum;

        // Slide window: remove one from left, add one from right each iteration
        for (int i = 1; i <= k; i++) {
            leftSum -= cardPoints[k - i];
            rightSum += cardPoints[n - i];
            maxSum = max(maxSum, leftSum + rightSum);
        }
        return maxSum;
    }
};
```

---

## Example

**Input:**

```
cardPoints = [1, 2, 3, 4, 5, 6, 1]
k = 3
```

**Output:**

```
12
```

**Explanation:**

Take three cards from the right end: 6 + 5 + 1 = 12, which is the maximum possible score.
