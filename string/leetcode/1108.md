# 1108. Defanging an IP Address

## 📘 Problem Statement
Given a valid (IPv4) IP address, return a defanged version of that IP address.  
A defanged IP address replaces every period `"."` with `"[.]"`.

---

### Example 1
**Input:**  
```
address = "1.1.1.1"
```
**Output:**  
```
"1[.]1[.]1[.]1"
```

### Example 2
**Input:**  
```
address = "255.100.50.0"
```
**Output:**  
```
"255[.]100[.]50[.]0"
```

---

### Constraints
- The given address is a valid IPv4 address.
- IPv4 addresses consist of digits and periods only.

---

## 💡 Approach
We iterate through each character of the string:
- If the character is `"."`, append `"[.]"` to the result.
- Otherwise, append the character itself.
  
This ensures all periods are replaced properly while keeping digits intact.

---

## 🧑‍💻 C++ Solution
```cpp
class Solution {
public:
    string defangIPaddr(string address) {
        int start = 0;
        string result;
        int end = address.size() - 1;
        while (start <= end) {
            if (address[start] == '.') {
                result += "[.]";
            } else {
                result += address[start];
            }
            start++;
        }
        return result;
    }
};
```

---

## ✅ Complexity Analysis
- **Time Complexity:** `O(n)` → We traverse the string once.  
- **Space Complexity:** `O(n)` → We store the defanged version in a new string.
