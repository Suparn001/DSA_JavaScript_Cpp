# 409. Longest Palindrome

## 📝 Problem Statement
Given a string `s` which consists of lowercase or uppercase letters, return the length of the longest palindrome that can be built with those letters.

Letters are **case sensitive**, for example, `"Aa"` is not considered a palindrome.

---

### Example 1:
**Input:**  
```
s = "abccccdd"
```
**Output:**  
```
7
```
**Explanation:**  
One longest palindrome that can be built is `"dccaccd"`, whose length is `7`.

---

### Example 2:
**Input:**  
```
s = "a"
```
**Output:**  
```
1
```
**Explanation:**  
The longest palindrome that can be built is `"a"`, whose length is `1`.

---

## ✅ Constraints
- `1 <= s.length <= 2000`
- `s` consists of lowercase and/or uppercase English letters only.

---

## 💡 Approach
1. Count the frequency of lowercase and uppercase letters separately.
2. For each character:
   - If the count is even, all of them can be part of the palindrome.
   - If the count is odd, one less than the count contributes, and mark that we can place a center character.
3. Finally, if there was any odd count, add `1` to the total length (for the middle character).

---

## 🚀 C++ Solution
```cpp
class Solution {
public:
    int longestPalindrome(string s) {
        vector<int> lower(26, 0);
        vector<int> upper(26, 0);
        bool odd = false;
        for (int i = 0; i < s.size(); i++) {
            if (s[i] >= 'a') {
                lower[s[i] - 'a']++;
            } else {
                upper[s[i] - 'A']++;
            }
        }

        int count = 0;
        // loop in lower and upper arrays
        for (int i = 0; i < 26; i++) {
            if (lower[i] % 2 == 0) {
                count += lower[i];
            } else {
                count += lower[i] - 1;
                odd = true;
            }

            if (upper[i] % 2 == 0) {
                count += upper[i];
            } else {
                count += upper[i] - 1;
                odd = true;
            }
        }

        if (odd)
            count += 1;

        return count;
    }
};
```

---

## 🔑 Key Takeaways
- Palindrome can use all even-count letters fully.
- Odd-count letters contribute all except one.
- At most one odd-count letter can be placed in the center of the palindrome.
