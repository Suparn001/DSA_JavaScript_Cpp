# Roman to Integer (LeetCode 13)

## 📌 Problem Statement
Roman numerals are represented by seven different symbols:

| Symbol | Value |
|--------|-------|
| I      | 1     |
| V      | 5     |
| X      | 10    |
| L      | 50    |
| C      | 100   |
| D      | 500   |
| M      | 1000  |

For example:
- `III` = 3  
- `XII` = 12 (`X` + `II`)  
- `XXVII` = 27 (`XX` + `V` + `II`)  

Roman numerals are usually written **largest to smallest**, but in special cases subtraction is used:
- `IV` = 4 (I before V → 5 − 1)  
- `IX` = 9  
- `XL` = 40  
- `XC` = 90  
- `CD` = 400  
- `CM` = 900  

Given a Roman numeral string `s`, convert it to an integer.

---

## 💡 Examples

**Example 1:**
```
Input:  s = "III"
Output: 3
```

**Example 2:**
```
Input:  s = "LVIII"
Output: 58
Explanation: L = 50, V = 5, III = 3
```

**Example 3:**
```
Input:  s = "MCMXCIV"
Output: 1994
Explanation: M = 1000, CM = 900, XC = 90, IV = 4
```

---

## 🚀 Solution Approach
1. Create a helper function `valueOfRoman(char)` that maps each Roman numeral character to its integer value.  
2. Traverse the string from left to right:
   - If the current numeral is **less than the next one**, subtract its value.  
   - Otherwise, add its value.  
3. At the end, add the value of the last character.  

This ensures subtraction rules (`IV`, `IX`, `XL`, etc.) are correctly handled.

---

## 🧑‍💻 Code (C++)
```cpp
class Solution {
public:
    int valueOfRoman(char x) {
        switch (x) {
            case 'I': return 1;
            case 'V': return 5;
            case 'X': return 10;
            case 'L': return 50;
            case 'C': return 100;
            case 'D': return 500;
            case 'M': return 1000;
            default: return 0; // invalid character
        }
    }

    int romanToInt(string s) {
        int start = 0;
        int last = s.size() - 1;
        int sum = 0;

        while (start < last) {
            if (valueOfRoman(s[start]) < valueOfRoman(s[start + 1])) {
                sum -= valueOfRoman(s[start]);
            } else {
                sum += valueOfRoman(s[start]);
            }
            start++;
        }

        // Add the last numeral
        return sum + valueOfRoman(s[last]);
    }
};
```

---

## ⏱ Complexity Analysis
- **Time Complexity:** `O(n)` → We scan the string once.  
- **Space Complexity:** `O(1)` → Only a few variables used, no extra data structures.
