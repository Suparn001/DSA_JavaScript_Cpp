
# 1832. Check if the Sentence Is Pangram

## 📝 Problem Description
A **pangram** is a sentence where every letter of the English alphabet appears at least once.  

Given a string `sentence` containing only lowercase English letters, return `true` if `sentence` is a pangram, or `false` otherwise.

### Example 1:
**Input:**
```
sentence = "thequickbrownfoxjumpsoverthelazydog"
```
**Output:**
```
true
```
**Explanation:**  
The sentence contains every letter from `a` to `z`.

---

### Example 2:
**Input:**
```
sentence = "leetcode"
```
**Output:**
```
false
```
**Explanation:**  
The sentence does not contain all 26 letters.

---

### Constraints:
- `1 <= sentence.length <= 1000`
- `sentence` consists of lowercase English letters.

---

## 💡 Approach
1. Create a vector of size 26 initialized with `0` to track the presence of each letter.
2. Traverse the string and mark each letter as present.
3. Finally, check if all 26 letters are marked.  
   - If yes → return `true`  
   - Else → return `false`

---

## ✅ Solution (C++)
```cpp
class Solution {
public:
    bool checkIfPangram(string sentence) {
        vector<int> check(26, 0);
        int start = 0;
        int end = sentence.size() - 1;

        while (start <= end) {
            char ch = sentence[start];
            int index = ch - 'a';
            check[index] = 1;
            start++;
        }

        for (auto& i : check) {
            if (i == 0) {
                return false;
            }
        }
        return true;
    }
};
```

---

## 🔑 Key Takeaways
- We only need to check **26 letters**, so the time complexity is **O(n)** where `n` is the length of the sentence.
- Space complexity is **O(1)** since the `check` array always has size 26.
