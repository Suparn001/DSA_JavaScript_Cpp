# 2785. Sort Vowels in a String

## Problem

You are given a 0-indexed string `s`. You need to permute `s` to get a
new string `t` such that:

-   All **consonants remain in their original places**.\
-   The **vowels must be sorted** in the non-decreasing order of their
    ASCII values.

The vowels are `a, e, i, o, u` and they can appear in lowercase or
uppercase.\
Consonants are all other English alphabet characters.

### Example 1

**Input:**

    s = "lEetcOde"

**Output:**

    "lEOtcede"

Explanation:\
- The vowels are `E, O, e`.\
- Sorting them by ASCII values → `E, O, e`.\
- Consonants (`l, t, c, d`) remain in the same place.

### Example 2

**Input:**

    s = "lYmpH"

**Output:**

    "lYmpH"

Explanation:\
- No vowels are present, so the string remains unchanged.

------------------------------------------------------------------------

## Constraints

-   `1 <= s.length <= 10^5`
-   `s` consists only of uppercase and lowercase English letters.

------------------------------------------------------------------------

## Solution (C++)

``` cpp
class Solution {
public:
    string sortVowels(string s) {
        vector<int> upper(26, 0);
        vector<int> lower(26, 0);
        string ans;
        int start = 0;
        char ch;
        int end = s.size() - 1;
        while (start <= end) {

            if (s[start] == 'A' || s[start] == 'E' || s[start] == 'I' ||
                s[start] == 'O' || s[start] == 'U') {
                upper[s[start] - 'A']++;
                s[start] = '#';
            }
            if (s[start] == 'a' || s[start] == 'e' || s[start] == 'i' ||
                s[start] == 'o' || s[start] == 'u') {
                lower[s[start] - 'a']++;
                s[start] = '#';
            }
            start++;
        }
        for (int i = 0; i < 26; i++) {
            char c = 'A' + i;
            while (upper[i]) {
                ans += c;
                upper[i]--;
            }
        }
        for (int i = 0; i < 26; i++) {
            char c = 'a' + i;
            while (lower[i]) {
                ans += c;
                lower[i]--;
            }
        }
        
        int first = 0;
        int second = 0;
        while (second < ans.size()) {
            if (s[first] == '#') {
                s[first] = ans[second];
                second++;
            }
            first++;
        }
        return s;
    }
};
```

------------------------------------------------------------------------

## Approach

1.  Traverse the string and extract vowels while marking their
    positions.\
2.  Count occurrences of vowels separately for uppercase and lowercase.\
3.  Reconstruct a sorted string of vowels.\
4.  Replace placeholders (`#`) in the original string with sorted
    vowels.

------------------------------------------------------------------------

## Complexity

-   **Time Complexity:** `O(n + 26)` → `O(n)`\
-   **Space Complexity:** `O(26 + n)` → `O(n)`
