# 1859. Sorting the Sentence

## 📝 Problem Statement
A sentence is a list of words that are separated by a single space with no leading or trailing spaces. Each word consists of lowercase and uppercase English letters.

A sentence can be **shuffled** by appending the 1-indexed word position to each word and then rearranging the words in the sentence.

Given a shuffled sentence `s` containing no more than 9 words, reconstruct and return the original sentence.

---

### Example 1:
**Input:**  
```
s = "is2 sentence4 This1 a3"
```
**Output:**  
```
"This is a sentence"
```
**Explanation:**  
Sorted order → `"This1 is2 a3 sentence4"`  
Remove indices → `"This is a sentence"`

---

### Example 2:
**Input:**  
```
s = "Myself2 Me1 I4 and3"
```
**Output:**  
```
"Me Myself and I"
```
**Explanation:**  
Sorted order → `"Me1 Myself2 and3 I4"`  
Remove indices → `"Me Myself and I"`

---

## ✅ Constraints
- `2 <= s.length <= 200`
- `s` consists of lowercase and uppercase English letters, spaces, and digits from `1` to `9`.
- The number of words in `s` is between `1` and `9`.
- The words in `s` are separated by a single space.
- `s` contains no leading or trailing spaces.

---

## 💡 Approach
1. Initialize a vector of size 10 to store words at their correct positions.
2. Iterate through the sentence and extract each word along with its index (last character).
3. Remove the digit from the word and place it in the correct index of the vector.
4. Finally, concatenate the words from `ans[1]` to `ans[n]` with spaces.

---

## 🚀 C++ Solution
```cpp
class Solution {
public:
    string sortSentence(string s) {
        vector<string> ans(10);
        string temp;
        int start = 0;
        int current = 0;
        int end = s.size() - 1;
        int integer;

        while (start <= end) {
            if (s[start] == ' ') {
                temp = s.substr(current, start - current);
                current = start + 1;
                integer = temp.back() - '0';
                temp.pop_back();
                ans[integer] = temp;
            }
            start++;
        }

        temp = s.substr(current, start - current);
        integer = temp.back() - '0';
        temp.pop_back();
        ans[integer] = temp;

        int size = 0;
        string result;
        for (int i = 0; i < 10; i++) {
            if (!ans[i].empty()) {
                size++;
            }
        }

        for (int i = 1; i <= size; i++) {
            if (!ans[i].empty()) {
                if (i < size) {
                    result += ans[i] + " ";
                } else {
                    result += ans[i];
                }
            }
        }
        return result;
    }
};
```

---

## 🔑 Key Takeaways
- Use the last character of each word to determine its original position.
- Store words in a fixed-size vector since maximum 9 words exist.
- Remove the number suffix before reconstructing the sentence.
