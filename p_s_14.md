# Celebrity Problem - README

## Problem Statement

A **celebrity** in a party is defined as a person:

* Who is **known by everyone else**.
* Who **does not know anyone** else at the party.

Given an `n x n` matrix `mat[][]`, where `mat[i][j] == 1` means person `i` knows person `j`, the task is to return the index (0-based) of the celebrity if one exists, otherwise return `-1`.

### Constraints

* `1 <= n <= 1000`
* `mat[i][j]` is either `0` or `1`
* `mat[i][i] == 1` (a person knows themselves)

### Examples

```text
Input:  mat = [[1, 1, 0], [0, 1, 0], [0, 1, 1]]
Output: 1
Explanation: 0 and 2 know 1, and 1 knows nobody else.

Input:  mat = [[1, 1], [1, 1]]
Output: -1
Explanation: Everyone knows everyone, hence no celebrity.

Input:  mat = [[1]]
Output: 0
Explanation: Only one person, they are trivially the celebrity.
```

## C++ Implementation

```cpp
#include <vector>
#include <stack>
using namespace std;

class Solution {
public:
    int celebrity(vector<vector<int>>& mat) {
        int n = mat.size();
        stack<int> st;

        // Step 1: Push all people to the stack
        for (int i = n - 1; i >= 0; i--) {
            st.push(i);
        }

        // Step 2: Eliminate non-celebrities
        while (st.size() > 1) {
            int first = st.top(); st.pop();
            int second = st.top(); st.pop();

            // If first knows second and second does not know first
            if (mat[first][second] && !mat[second][first]) {
                st.push(second);
            } else if (!mat[first][second] && mat[second][first]) {
                st.push(first);
            }
            // If both know each other or neither knows the other, eliminate both
        }

        if (st.empty()) return -1;

        int num = st.top();
        int row = 0, col = 0;

        for (int i = 0; i < n; i++) {
            if (i != num) {
                row += mat[num][i];     // Celebrity should not know anyone
                col += mat[i][num];     // Everyone should know celebrity
            }
        }

        return (row == 0 && col == n - 1) ? num : -1;
    }
};
```

## Java Implementation

```java
import java.util.Stack;

class Solution {
    int celebrity(int[][] mat, int n) {
        Stack<Integer> st = new Stack<>();

        // Step 1: Push all people into the stack
        for (int i = n - 1; i >= 0; i--) {
            st.push(i);
        }

        // Step 2: Eliminate non-celebrities
        while (st.size() > 1) {
            int first = st.pop();
            int second = st.pop();

            // If first knows second and second does not know first
            if (mat[first][second] == 1 && mat[second][first] == 0) {
                st.push(second);
            } else if (mat[first][second] == 0 && mat[second][first] == 1) {
                st.push(first);
            }
            // If both know each other or neither knows the other, eliminate both
        }

        if (st.isEmpty()) return -1;

        int num = st.pop();
        int row = 0, col = 0;

        for (int i = 0; i < n; i++) {
            if (i != num) {
                row += mat[num][i];     // Celebrity should not know anyone
                col += mat[i][num];     // Everyone should know celebrity
            }
        }

        return (row == 0 && col == n - 1) ? num : -1;
    }
}
```

---

## Time and Space Complexity

* **Time Complexity:** O(n)

  * Each person is pushed and popped from the stack once, and the final verification is done in O(n)
* **Space Complexity:** O(n)

  * Stack is used to hold up to n elements

---

## Approach Summary

1. Push all people into a stack.
2. Pop two people at a time and compare:

   * If `A` knows `B`, then `A` cannot be a celebrity.
   * If `A` doesn't know `B`, then `B` cannot be a celebrity.
3. One potential candidate remains.
4. Validate the candidate:

   * They should not know anyone (check row)
   * Everyone should know them (check column)

Return the index if conditions match; otherwise return `-1`.
