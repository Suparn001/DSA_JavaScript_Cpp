# Leetcode 1394: Find Lucky Integer in an Array

## 🧩 Problem Description

A **lucky integer** in an array is an integer whose **frequency** in the array is **equal to its value**.

Given an array of integers `arr`, return the **largest lucky integer**.  
If there is **no** lucky integer, return `-1`.

### 📝 Constraints

- 1 <= arr.length <= 500  
- 1 <= arr[i] <= 500

---

## 💡 Examples

### Example 1
**Input:** `arr = [2, 2, 3, 4]`  
**Output:** `2`  
**Explanation:** Only number 2 has frequency = 2.

---

### Example 2
**Input:** `arr = [1, 2, 2, 3, 3, 3]`  
**Output:** `3`  
**Explanation:** 1 appears once, 2 appears twice, 3 appears three times. All are lucky, return the **largest**.

---

### Example 3
**Input:** `arr = [2, 2, 2, 3, 3]`  
**Output:** `-1`  
**Explanation:** No number has a frequency equal to its value.

---

## ⚙️ Logic and Approach

### ✅ Key Insight

To solve this efficiently **in-place**, we use a clever trick:

- A 32-bit integer can be used to store **two** pieces of information:
  - Lower 16 bits: original number
  - Upper 16 bits: frequency count

We encode the frequency in the **upper 16 bits** of each element (using bitwise manipulation) and then extract it to find if the value is "lucky".

---

## 🧠 Why Use Bit Manipulation?

This method avoids using extra space (like a hash map or array).  
Using 32-bit space cleverly helps in storing frequency **without modifying** the original value in the lower 16 bits.

---

## 🚀 Java Solution

```java
class Solution {
    public int findLucky(int[] arr) {
        int n = arr.length;

        // First pass: encode frequency in upper 16 bits
        for (int i = 0; i < n; i++) {
            int value = arr[i] & 65535; // get lower 16 bits (original value)
            if (value <= n) {
                arr[value - 1] += 1 << 16; // increment frequency count in upper 16 bits
            }
        }

        // Second pass: find the largest lucky number
        for (int val = n; val > 0; val--) {
            if ((arr[val - 1] >> 16) == val) { // check if frequency == value
                return val;
            }
        }

        return -1;
    }
}
```

## 🚀 C++ Solution

```CPP
class Solution {
public:
    int findLucky(vector<int>& arr) {
        int n = arr.size();
        for (int& num : arr) {
            int value = num & 65535;
            if (value <= n) {
                arr[value - 1] += pow(2, 16); // can aldso be written in 1<<16
            }
        }

        for (int val = n; val > 0; val--) {
            if (arr[val - 1] >> 16 == val) {
                return val;
            }
        }

        return -1;
    }
};
```
