# Check if One String Swap Can Make Strings Equal

## Problem Statement
You are given two strings `s1` and `s2` of equal length. A string swap is an operation where you choose two indices in a string (not necessarily different) and swap the characters at these indices.

Return `true` if it is possible to make both strings equal by performing at most **one** string swap on exactly **one** of the strings. Otherwise, return `false`.

## Examples

### Example 1
**Input:**  
```plaintext
s1 = "bank"
s2 = "kanb"
```
**Output:**  
```plaintext
true
```
**Explanation:**  
Swapping the first character with the last character in `s2` makes it "bank".

---

### Example 2
**Input:**  
```plaintext
s1 = "attack"
s2 = "defend"
```
**Output:**  
```plaintext
false
```
**Explanation:**  
It is impossible to make them equal with just one swap.

---

### Example 3
**Input:**  
```plaintext
s1 = "kelb"
s2 = "kelb"
```
**Output:**  
```plaintext
true
```
**Explanation:**  
The two strings are already equal, so no swap is needed.

## Constraints
- `1 <= s1.length, s2.length <= 100`
- `s1.length == s2.length`
- `s1` and `s2` consist of only lowercase English letters.

## Approach
1. **Check if `s1` and `s2` are already equal**: If they are the same, return `true` immediately.
2. **Find mismatched indices**: Identify the positions where `s1` and `s2` differ.
   - If **more than two mismatches**, return `false`.
   - If **exactly two mismatches**, check if swapping the characters would make them equal.
3. **Return the result based on swap possibility.**

## Complexity Analysis
- **Time Complexity:** `O(n)`, where `n` is the length of the string (since we traverse the strings at most twice).
- **Space Complexity:** `O(1)`, as only a few variables are used for counting mismatches.

## Edge Cases Considered
- Strings are already equal (`s1 == s2`).
- Strings differ at more than two positions.
- Strings have exactly two mismatches that can be swapped.
- Minimum and maximum length constraints.



1st appreach->
```cpp
class Solution {
public:
    bool areAlmostEqual(string s1, string s2) {
        int n = s1.length();
        if (s1 == s2) {
            return true;
        }
        int frequency1[26] = {0};
        int frequency2[26] = {0};
        int countDifference = 0;
        for (int i = 0; i < n; i++) {
            if (s1[i] != s2[i]) {
                countDifference++;
            }

            if (countDifference > 2) {
                return false;
            }

            frequency1[s1[i] - 'a']++;
            frequency2[s2[i] - 'a']++;
        }

        for (int i = 0; i < 26; i++) {
            if (frequency1[i] != frequency2[i]) {
                return false;
            }
            
        }
        return true;
    }
};
```

```cpp
class Solution {
public:
    bool areAlmostEqual(string s1, string s2) {
        int n = s1.length();
        if (s1 == s2) {
            return true;
        }
        int index1 = 0;
        int index2 = 0;
        int countDifference = 0;
        for (int i = 0; i < n; i++) {
            if (s1[i] != s2[i]) {
                countDifference++;
                if (countDifference > 2) {
                    return false;
                } else if (countDifference == 1) {
                    index1 = i;
                } else {
                    index2 = i;
                }
            }
        }
        return s1[index1] == s2[index2] && s1[index2] == s2[index1];
    }
};
```
