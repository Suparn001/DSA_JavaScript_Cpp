# 812. Largest Triangle Area

This repository contains a **C++ solution** to the LeetCode problem [812. Largest Triangle Area](https://leetcode.com/problems/largest-triangle-area/).

## Problem Description

Given an array of points on the X-Y plane `points` where `points[i] = [xi, yi]`, return the area of the **largest triangle** that can be formed by any three different points.  

**Note:** Answers within `10^-5` of the actual answer will be accepted.

### Constraints
- `3 <= points.length <= 50`
- `-50 <= xi, yi <= 50`
- All points are **unique**.

### Examples

**Example 1:**
```
Input: points = [[0,0],[0,1],[1,0],[0,2],[2,0]]
Output: 2.00000
```

**Example 2:**
```
Input: points = [[1,0],[0,0],[0,1]]
Output: 0.50000
```

## Solution Approaches

### 1. Using Shoelace Formula (Determinant Method)

For points `(x1,y1), (x2,y2), (x3,y3)`:

```
Area = 0.5 * | x1*(y2 - y3) + x2*(y3 - y1) + x3*(y1 - y2) |
```

This method iterates through all possible triplets of points and keeps track of the maximum area.

#### C++ Code:

```cpp
#include <vector>
#include <cmath>
#include <algorithm>
using namespace std;

class Solution {
public:
    double largestTriangleArea(vector<vector<int>>& points) {
        double result = 0.0;
        int n = points.size();

        for (int i = 0; i < n; i++) {
            for (int j = i + 1; j < n; j++) {
                for (int k = j + 1; k < n; k++) {
                    int x1 = points[i][0], y1 = points[i][1];
                    int x2 = points[j][0], y2 = points[j][1];
                    int x3 = points[k][0], y3 = points[k][1];

                    double area = 0.5 * fabs(x1*(y2 - y3) +
                                             x2*(y3 - y1) +
                                             x3*(y1 - y2));

                    result = max(result, area);
                }
            }
        }
        return result;
    }
};
```

### 2. Using `hypot` and Heron's Formula

Alternatively, the area can be calculated using **Heron's formula** with `hypot` to compute distances between points:

\[
\text{Area} = \sqrt{s \cdot (s-a) \cdot (s-b) \cdot (s-c)}
\]

Where:
- \(a, b, c\) are the lengths of the triangle sides
- \(s = (a+b+c)/2\) is the semi-perimeter

#### C++ Code with `hypot`:

```cpp
#include <vector>
#include <cmath>
#include <algorithm>
using namespace std;

class Solution {
public:
    double largestTriangleArea(vector<vector<int>>& points) {
        double result = 0.0;
        int n = points.size();

        for (int i = 0; i < n; i++) {
            for (int j = i + 1; j < n; j++) {
                for (int k = j + 1; k < n; k++) {
                    double a = hypot(points[i][0] - points[j][0],
                                     points[i][1] - points[j][1]);
                    double b = hypot(points[j][0] - points[k][0],
                                     points[j][1] - points[k][1]);
                    double c = hypot(points[k][0] - points[i][0],
                                     points[k][1] - points[i][1]);

                    double s = (a + b + c) / 2.0;
                    double area = sqrt(s * (s - a) * (s - b) * (s - c));

                    result = max(result, area);
                }
            }
        }
        return result;
    }
};
```

### How to Use

1. Create a new C++ file (e.g., `LargestTriangleArea.cpp`).  
2. Copy either the **Shoelace formula version** or **Hypot version** into the file.  
3. Compile and run using a C++ compiler:
```bash
g++ LargestTriangleArea.cpp -o LargestTriangleArea
./LargestTriangleArea
```
4. Call `largestTriangleArea` by passing a `vector<vector<int>>` of points.

---

### Notes

- Both approaches are **O(n³)**, which is fine for small `n` (≤50).  
- `hypot` automatically calculates the Euclidean distance between two points.  
- Using `0.5` avoids integer division issues, and `fabs` ensures positive area.
