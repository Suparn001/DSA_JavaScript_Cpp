# 976. Largest Perimeter Triangle

## Problem Statement
Given an integer array `nums`, return the **largest perimeter** of a triangle with a **non-zero area**, formed from three of these lengths.  
If it is impossible to form any triangle of non-zero area, return `0`.

### Example 1:
**Input:**
```
nums = [2,1,2]
```
**Output:**
```
5
```
**Explanation:**  
You can form a triangle with three side lengths: `1, 2, and 2`.  
Its perimeter is `1 + 2 + 2 = 5`.

---

### Example 2:
**Input:**
```
nums = [1,2,1,10]
```
**Output:**
```
0
```
**Explanation:**  
- `1, 1, 2` → not a triangle  
- `1, 1, 10` → not a triangle  
- `1, 2, 10` → not a triangle  
Thus, no valid triangle can be formed.

---

## Constraints
- 3 ≤ nums.length ≤ 10^4  
- 1 ≤ nums[i] ≤ 10^6  

---

## Approach

1. **Sort the array** in ascending order.  
2. Since the triangle inequality requires:
   ```
a + b > c
```
   where `c` is the largest side, we only need to check the **last three numbers** repeatedly.  
3. Iterate from the end of the sorted array:
   - If `nums[i-2] + nums[i-1] > nums[i]`, then these three sides form the **largest perimeter triangle** (since larger numbers are checked first).
   - Return their sum immediately.  
4. If no valid triple is found, return `0`.

---

## Code (C++)

```cpp
class Solution {
public:
    int largestPerimeter(vector<int>& nums) {
        sort(nums.begin(), nums.end()); // ascending order
        for (int i = nums.size() - 1; i >= 2; i--) {
            if (nums[i - 2] + nums[i - 1] > nums[i]) {
                return nums[i] + nums[i - 1] + nums[i - 2];
            }
        }
        return 0;
    }
};
```

---

## Complexity Analysis
- **Sorting:** O(n log n)  
- **Loop:** O(n)  
- **Total:** O(n log n)  

✅ Efficient enough for n ≤ 10^4.
