# 🧭 Minimum Time Visiting All Points (LeetCode 1266)

## 📌 Problem Statement

On a 2D plane, you are given `n` points in a specific order.  
Each point is represented as:

```
points[i] = [xi, yi]
```

You must visit **all points in the given order**.

### ⏱ Movement Rules (per 1 second)

You can:
- Move **vertically** by 1 unit  
- Move **horizontally** by 1 unit  
- Move **diagonally** (1 unit in x and 1 unit in y)

You are allowed to **pass through other points**, but only visiting the exact points in order counts.

---

## 🎯 Objective

Return the **minimum time (in seconds)** required to visit all points in order.

---

## 🧠 Key Insight

To move from point **A(x₁, y₁)** to **B(x₂, y₂)**:

- Horizontal distance → `dx = |x₂ - x₁|`
- Vertical distance → `dy = |y₂ - y₁|`

Since diagonal movement covers **both x and y in 1 second**, the optimal strategy is:
- Use diagonal moves as much as possible
- Cover remaining distance using straight moves

### ✅ Minimum Time Formula

```
time = max(dx, dy)
```

---

## 💻 C++ Implementation

```cpp
class Solution {
public:
    int minTimeToVisitAllPoints(vector<vector<int>>& points) {
        int totalSteps = 0;

        for (int i = 0; i < points.size() - 1; i++) {
            totalSteps += max(
                abs(points[i + 1][0] - points[i][0]),
                abs(points[i + 1][1] - points[i][1])
            );
        }

        return totalSteps;
    }
};
```

## 🎤 Interview Tip

> Because diagonal moves reduce both x and y together, the minimum time between two points is the maximum of the horizontal and vertical distances.
